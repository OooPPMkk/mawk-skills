# 新会话接续稿模板

会话过长时产出下面这段，用户复制到新会话即可无缝接续（新会话按 plan §1「新会话接续」流程载入上下文）。

```markdown
推进 B<n>。先按 ai-school-integration-plan.md 的「新会话接续」流程载入上下文
（plan §1 / §2 / §5 + ai-school-integration-history.md 的 D<n> 与 B<n-1> / B<n> 小节
+ harness v3 `XXX-n`），然后按 §2 的 B<n> 范围执行（<一句话范围概述>）。

前一批 B<n-1> 已提交（<SHA>），文档已回写。

本批已知口径：
- <口径 1>
- <口径 2>

待确认（有则在实施前提问）：
1. <决策点>
```

要点：

- 只带**必要的**上下文清单（具体到 § 与 `Dn` / `Bxx`），不要泛读全仓。
- 前一批的提交 SHA 与文档回写状态要写清，避免新会话重复回写。
- 把「已定口径」和「待确认」分开写：已定的不要重复问，待确认的要在实施前提。
